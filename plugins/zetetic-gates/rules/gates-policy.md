# Shared Zetetic gates

This plugin applies the same mechanical quality controls to every project.
Before committing, run the project's applicable tests and inspect the staged diff.
Code must satisfy the source-discipline and craftsmanship checkers. Cite evidence
for algorithm choices and measured claims; a source marker alone does not prove
that a reference is valid or that an experiment supports the claim.

Before returning or publishing prose, remove the writing patterns identified by
the redaction checker. Preserve meaning and evidence when rewriting. A mechanical
scan does not establish authorship or replace editorial judgment.

The plugin checks staged code before agent-issued commits and scans returned and
published prose. Edit-time source/layer hints remain advisory; commit checks are
authoritative. Repository-specific tests and configuration supplement these rules.
Read rules/coding-standards.md in this plugin for the detailed standard.
