# Strauss: code qualitative evidence systematically

Use this reference for interviews, tickets, field notes, reviews or other
qualitative material where anecdotes must become a traceable set of categories
and relationships.

## Procedure

1. Preserve source identity, context and consent constraints before coding.
2. Code closely against the data with short labels that describe actions,
   meanings or conditions. Keep excerpts linked to their source locations.
3. Compare each incident with earlier incidents and revise codes when the data
   no longer fit.
4. Write memos that separate data, code definitions, analytical ideas and
   unresolved questions.
5. Group related codes into categories with properties, conditions,
   interactions and consequences.
6. Sample further material to challenge or refine emerging categories.
7. Stop only with a documented saturation argument and actively preserved
   negative cases.

## Output

- Corpus and sampling record
- Codebook with definitions and source-linked examples
- Category map and analytical memos
- Negative cases and category revisions
- Saturation assessment
- Qualified theory or themes with transfer limits

## Cautions

- Frequency is not equivalent to importance.
- Early categories can cause later evidence to be forced into the wrong frame.
- “Saturation” is a claim requiring a visible sampling and memo trail.
- Refuse population-level prevalence claims from qualitative coding alone.
