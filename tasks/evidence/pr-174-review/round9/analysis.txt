Class (not the one row)
-----------------------
"A command name the shell builds at run time." Where origin/main refused
(_flat_targets is None), git_commands now also refuses when the rewritten
text or a dropped non-heredoc span, quotes removed, holds such a name:

  command position  start of text or line, after ; & | ( { ` ! and after the
                    reserved words then do else elif if while until time;
                    after ) too when the text holds the word case (a case
                    pattern's ) is followed by a command; elsewhere ) would
                    make $x in `echo $(date) $x` a command name);
                    NAME=value assignment prefixes and redirections
                    ([n]op word: >/dev/null ${x}t, 2>&1 ${x}t) are skipped;
                    a redirection target holding $, a backtick or ( counts
                    as built (process substitution <(...) runs a command).
  built name        the word holds $ or a backtick (parameter, command and
                    arithmetic expansion: ${x}t, $(printf gi)t, `echo gi`t,
                    $'...'), a pathname-expansion character * ? [ (except the
                    words [ and [[), or a brace expansion {a,b} / {a..b}.
  prefix words      command env sudo doas exec builtin nohup nice time timeout
                    stdbuf setsid eval coproc, and zsh's precommand modifiers
                    noglob nocorrect -: every later word of the simple command
                    counts (env -i PATH=.. ${x}t, exec ${x}t, eval "${x}t").
                    The list is not exhaustive: any program that runs its
                    arguments (chroot, flock, watch, ...) is outside it.
  builders          xargs, parallel: they build the command line from input
                    (echo gi | xargs -I@ @t commit), so they count as built.
  sh -c '...'       quotes are removed first (shell_text.unquoted), so the
                    string's ; and words are scanned like live text.

  5-8 follow: both rules ran first.

Bound (knuth): builds_command_name is O(n) in the unquoted text.
  - A text holding none of $ ` * ? [ { or the words xargs/parallel is spared
    by one regex pass (_CANDIDATE): every built word or builder holds one.
  - Otherwise one finditer over command positions; at each position not
    inside text already examined, one word match (or, after a prefix word,
    one match of the rest of the simple command). Positions inside examined
    text are skipped, so the word and rest scans are disjoint:
    test_each_character_is_examined_by_at_most_one_word_scan.
  source: measured 2026-10-17, load ~290, 131 000 chars: ';'*n 0.002 s,
  source: same run: ('A=1 time '*n) 0.002 s, ('{ '*n) 0.91 s, the slowest
  shape found (shell_text.read on ';'*n: 1.9 s at the same load).

Residual (not closed; listed in the PR body): c_r9_residual_b.py, R3-R5
  A static command name that resolves to a git copied or linked at run time:
    p=$(printf gi)t; cp "$(which "$p")" ./x; ./x commit       (R3)
    p=gi; ln -sf "$(which "${p}t")" ./x; ./x commit            (R4)
    ... cp ... b/x; PATH=$PWD/b:$PATH x commit                 (R5)
  The built word is an argument of which/cp/ln, not a command name. bash and
  zsh run the commit (checked with a shim before the harness run);
  origin/main refused all three (data git followed by a blank); the new head
  returns []. These are FAIL-OPEN-REGRESSION rows against origin/main, outside
  the round-9 class. No list of commands closes them: a static name can be
  made to resolve to git by cp, ln, install, PATH, a write into a PATH
  directory, an alias or hash. The rule that would close them: where
  origin/main refused, spare only commands whose every command name is on an
  allowlist of programs that run no other program (mkdir, cat, echo, ...),
  and refuse otherwise. It costs nothing against origin/main but refuses
  again much that f646e4e spares; it is an owner decision.
